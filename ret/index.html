Abstract

Abstract

Classical game theory models strategic decision-making through payoff maximization, with Nash equilibrium representing stable states from which no agent benefits from unilateral deviation. However, Nash theory cannot explain numerous empirically observed phenomena including cooperation under risk, symbolic focal point selection, framing effects, and communication-induced coordination. We introduce Resonant Equilibrium Theory (RET), a field-theoretic expansion of game dynamics that incorporates symbolic compression, temporal rhythm, phase alignment, and field curvature as fundamental state variables.

RET operates on the Delta Harmonic Vector (ΔHV) computational substrate, which provides operational definitions for all theoretical constructs. The framework introduces coherence costs—energetic penalties for field misalignment—that modify classical utility functions: ũᵢ = uᵢ - Cᵢ. We demonstrate that Nash equilibrium emerges as the limiting case when coherence costs vanish (Cᵢ → 0), establishing RET as a strict superset of classical theory.

Through systematic empirical validation across 9 behavioral game theory benchmarks from published literature, we demonstrate that RET outperforms Nash equilibrium predictions by 19-70% (mean absolute error reduction), with particularly strong results on held-out test data. The framework correctly predicts communication-induced cooperation in Prisoner's Dilemma (70% predicted vs 72% empirical, compared to Nash's 0% prediction), captures framing effects that Nash treats as irrelevant, and explains equilibrium selection in Stag Hunt games.

RET identifies five distinct equilibrium mechanisms: (1) Gradient-Based Basins (classical Nash), (2) Resonance-Locked Basins (temporal entrainment), (3) Recursively-Evoked Basins (symbolic field attraction), (4) Interference Zones (phase destabilization), and (5) Precessive Shifts (anticipatory field responses). We provide fully specified experimental designs for laboratory validation and discuss applications to AI multi-agent systems, mechanism design, and social coordination.

Keywords: game theory, Nash equilibrium, field theory, symbolic dynamics, phase coherence, behavioral economics, multi-agent systems

1. Introduction

1. Introduction

1.1 The Nash Equilibrium Gap

Game theory has provided powerful tools for modeling strategic interaction since Nash's (1950) foundational work established equilibrium as the central solution concept. A Nash equilibrium is a strategy profile where no player can improve their payoff through unilateral deviation—a fixed point in the space of mutual best responses.

However, extensive empirical research in behavioral game theory has revealed systematic deviations from Nash predictions:

  • Communication effects: Pre-game discussion increases cooperation in Prisoner's Dilemma from 40% to 72% (Dawes et al., 1977), despite cheap talk theorems predicting no effect
  • Framing effects: Identical payoff structures yield 33% cooperation when labeled "Wall Street Game" versus 66% when labeled "Community Game" (Liberman et al., 2004)
  • Focal point selection: Agents coordinate on salient options in symmetric games with multiple equilibria (Schelling, 1960; Mehta et al., 1994)
  • Temporal coordination: Rhythmic cues facilitate cooperation even in one-shot interactions (Wiltermuth & Heath, 2009)
  • Anticipatory behavior: Agents shift strategies before payoff structures justify the change (Haruvy & Stahl, 2004)

Classical extensions—repeated games, incomplete information, evolutionary dynamics—capture some of these phenomena but lack a unified framework explaining how symbolic content, temporal structure, and phase relationships fundamentally shape equilibrium selection.

1.2 Theoretical Motivation

We propose that strategic decision-making occurs not in an abstract payoff space, but within multidimensional coherence fields characterized by:

  1. Symbolic structure (S): The clarity and compression of shared meanings, narratives, and conceptual frameworks
  2. Temporal rhythm (R): The characteristic timing patterns and synchronization of decision processes
  3. Phase alignment (δφ): The degree of temporal and contextual synchrony between agents
  4. Field curvature (H): The topological shape of attractor basins in the expanded state space

    5. These dimensions are not epiphenomenal—they impose real coherence costs on agents attempting to occupy misaligned states. Just as physical systems minimize free energy, strategic agents minimize coherence-adjusted utility.

    1.3 The RET Framework

    Resonant Equilibrium Theory (RET) formalizes this intuition by introducing coherence-modified utility:

    ũ_i = u_i - C_i

    where:

    • u_i is classical payoff-based utility
    • C_i is the coherence cost function decomposed into symbolic, temporal, phase, and field components
    • ũ_i is the effective utility agents actually optimize

    A RET equilibrium is a strategy profile s^* satisfying:

    (∂ ũ_i) / (∂ s_i) = 0 ∀ i, and Σ_i C_i(s^*) is minimized across accessible basins

    Critically, when all coherence costs vanish (C_i = 0), this reduces to the classical Nash condition, establishing:

    Nash ⊂ RET

    Nash equilibrium is the special case; RET provides the general framework.

2. Theoretical Framework

2.1 Core Definitions

We establish precise mathematical definitions for RET's fundamental constructs.

Definition 2.1.1: Delta Harmonic Vector (ΔHV)

The ΔHV is a four-dimensional state vector representing an agent's position in coherence field space:

x⃗_i = {S_i, R_i, φ_i, H_i}

where:

  • S_i \in [0,1]: Symbolic compression (information density of agent's conceptual framework)
  • R_i \in [0,1]: Temporal rhythm (characteristic frequency of decision cycles)
  • φ_i \in [0, 2\pi]: Phase angle (temporal position within decision cycle)
  • H_i \in [0,1]: Field harmony (alignment with environmental field structure)

The "delta" (Δ) signifies that we measure changes and convergences in this space, not just static positions.

Definition 2.1.2: Symbolic Compression S(Vᵢ)

For agent i with interpretive framework V_i (represented as an embedding vector), symbolic compression is defined via cosine similarity to a sanctified reference vector V_{ref}:

S(V_i) = cos(θ_{i,ref}) = (V_i · V_{ref}) / (‖V_i‖ ‖V_{ref)‖}

Interpretation: High S indicates the agent's symbolic framework is aligned with a shared or canonical meaning structure. Low S indicates divergent or idiosyncratic interpretations.

Operational measurement: Using NLP embedding models (e.g., sentence-BERT, GPT embeddings), extract vector representations of agent communications and compute cosine similarity to a predefined reference frame.

Definition 2.1.3: Temporal Rhythm R(τᵢ)

The rhythm component combines phase synchrony and message rate:

R(τ_i) = 0.5 · (1 - CV(Δφ_i)) + 0.5 · ((m_i) / (m_{max)})

where:

  • CV(\Deltaφ_i) is the circular variance of phase differences (0 = perfect periodicity)
  • m_i is agent i's message/decision rate
  • m_max is a normalization constant (e.g., 8 messages per minute)

Interpretation: High R indicates regular, predictable decision timing. Low R indicates erratic or unpredictable rhythms.

Operational measurement: Track timestamps of agent actions/communications and compute inter-event interval distributions. Phase differences extracted via Hilbert transform or direct circular statistics.

Definition 2.1.4: Phase Misalignment δφ(τ)

Phase misalignment is a composite measure of three drift components:

δφ(τ) = Clamp(0.45 · D_c + 0.35 · E_d + 0.20 · T_j, 0, 1)

where:

  • D_c: Conceptual drift (cosine distance between consecutive intent embeddings)
  • E_d: Emotional drift (change in affect scores via sentiment analysis)
  • T_j: Temporal jitter (variance in inter-message intervals normalized)

Interpretation: Low δφ means agent maintains consistent conceptual, emotional, and temporal positioning. High δφ indicates instability or incoherence.

Operational measurement:

  • D_c: Compute embedding similarity across consecutive turns
  • E_d: Use affective computing models to track mood shifts
  • T_j: Measure coefficient of variation in timing intervals

Definition 2.1.5: Field Curvature H(μ, Σ, τ)

Field curvature measures how well the current field configuration maintains coherent structure:

H(μ, Σ, τ) = 1 - (L_{rec}) / (L_ref}

where:

  • L_{rec}: Reconstruction loss from autoencoder attempting to compress field state
  • L_{ref}: Baseline reference loss (e.g., random field configuration)

Interpretation: High H indicates a well-structured, low-entropy field (stable attractor basin). Low H indicates chaotic or disordered field (interference zone).

Operational measurement: Train a simple autoencoder (dense or transformer-based) on field state vectors. Reconstruction fidelity indicates field regularity.

2.2 The ΔHV Convergence Expression

The complete harmonic convergence for agent i is:

Δ HV_i = (S_i^{w_S} · R_i^{w_R} · (1-δφ_i)^{w_F} · H_i^{w_H})^{(1) / (w_S + w_R + w_F + w_H)}

where w_S, w_R, w_F, w_H are tunable weights controlling the relative influence of each dimension. Default values:

w_S = 0.30, w_R = 0.30, w_F = 0.20, w_H = 0.20

This weighted geometric mean ensures:

  • All components contribute multiplicatively (zero in any dimension collapses ΔHV)
  • Weights can be empirically calibrated for different game types
  • The measure is scale-invariant (normalized to [0,1])

Physical interpretation: \Delta HV_i represents the coherence resonance of agent i with the field. High ΔHV = agent is in harmony; low ΔHV = agent is misaligned and experiencing high coherence costs.

2.4 Action-Conditional Coherence Costs

Critical innovation: Coherence costs depend not only on agent state but also on the action chosen given field conditions.

Definition 2.4.1: Field Cooperation Score

ψ(x⃗_i) = 0.50 · S_i + 0.30 · (1 - δφ_i) + 0.20 · H_i

Interpretation: \psi \in [0,1] measures how much the current field favors cooperative/aligned actions versus defection/competition.

Definition 2.4.2: Action Alignment Cost

For agent i choosing action a \in \{A, B\} (where A = cooperate/coordinate, B = defect/compete):

C_{align}(a) =
λ_{align} · (1 - ψ)^2 if a = A

λ_{align} · ψ^2 if a = B

Key insight:

  • When field favors cooperation (\psi \approx 1), choosing cooperation has low cost, defection has high cost
  • When field favors competition (\psi \approx 0), choosing defection has low cost, cooperation has high cost

This creates field-based incentives that Nash equilibrium completely lacks.

Total Coherence Cost (Action-Conditional)

C_i(a) = C_{base} + C_{align}(a)

where C_{base} is the structural cost from phase, symbolic, temporal, and field misalignment (independent of action).

2.5 RET Equilibrium Condition

A strategy profile s^ = (s_1^, ..., s_n^*) is a RET equilibrium if:

(∂ ũ_i) / (∂ s_i)|_{s^*} = 0 ∀ i

and

Σ(i=1)^n C_i(s^*) = min(s ∈ ℬ) Σ(i=1)^n C_i(s)

where ℬ is the set of basins accessible from initial conditions.

Interpretation: A RET equilibrium is both a local optimum (no unilateral deviation improves ũ_i) and a global coherence minimum (total field misalignment is minimized).

2.6 Relationship to Nash Equilibrium

Theorem 2.6.1 (Nash as Limiting Case)

When all coherence costs vanish:

λ_{φ} = λ_S = λ_R = λ_H = λ_{align} = 0 ⟹ C_i = 0 ⟹ ũ_i = u_i

Then the RET equilibrium condition reduces to:

(∂ u_i) / (∂ s_i)|_{s^*} = 0 ∀ i

which is precisely the Nash equilibrium condition.

∴ Nash ⊂ RET

Proof sketch: With C_i \equiv 0, coherence-adjusted utility equals classical utility. The minimization over basins becomes irrelevant (all points have equal coherence cost zero), and we recover standard local optimality. ∎

Corollary: Any Nash equilibrium is a valid RET equilibrium when coherence costs are zero. RET extends but does not contradict Nash theory.

2.7 Emergence Degree Function

To model probabilistic basin selection, we define:

E_{deg}(Δ HV) = (1) / (1 + e^{-k(Δ HV - θ_E))}

where:

  • k: Steepness parameter (controls how sharply ΔHV thresholds affect emergence)
  • \theta_E: Threshold value (critical ΔHV for basin activation)

Interpretation: E_{deg} gives the probability that a basin with coherence \Delta HV will be selected. High ΔHV basins are strongly preferred; low ΔHV basins are avoided.

This sigmoid formulation allows RET to make probabilistic equilibrium predictions, not just binary yes/no statements.

4. The Five Mechanisms

4. The Five RET Mechanisms

We now characterize each equilibrium mechanism with formal definitions, activation conditions, and empirical examples.

4.1 RET-1: Gradient-Based Basins

Definition: Classical Nash-type equilibria where payoff gradients dominate and coherence costs are negligible.

Activation condition:

all λ_n ≈ 0 OR Δ HV ≈ 0.5 (neutral field)

Mathematical signature:

∇ ũ_i ≈ ∇ u_i (coherence gradient negligible)

Behavioral signature: Agents behave according to rational choice theory; framing, timing, and symbolism have minimal impact.

Empirical example: PD-Neutral condition where RET predictions converge to Nash (33% vs 40% observed, both far from Nash's 0%).

Basin topology: Shallow local minima defined by payoff structure alone.

4.2 RET-2: Resonance-Locked Basins

Definition: Equilibria stabilized through temporal entrainment and phase synchronization.

Activation condition:

R_i ≥ 0.75 AND δφ_i ≤ 0.25 (high rhythm, low phase drift)

Mathematical signature:

λ_R |R_i - R̄| ≪ λ_{φ} ‖δφ_i‖^2 (temporal alignment dominates)

Behavioral signature: Agents coordinate not through explicit communication but via rhythmic synchrony. Cooperation emerges from "being in sync."

Empirical example: Stag Hunt with pre-play signaling (80% cooperation) - agents entrain through repeated signaling exchanges before formal choice.

Basin topology: Limit cycles or stable fixed points with temporal oscillations. Breaking rhythm incurs high cost.

Mechanism analogy: Kuramoto oscillator phase-locking.

4.3 RET-3: Recursively-Evoked Basins

Definition: Equilibria where symbolic field recognition pulls agents toward shared attractors.

Activation condition:

S_i ≥ 0.75 AND H_i ≥ 0.50 (high symbolic clarity, stable field)

Mathematical signature:

λ_S D_{KL}(S(V_i) ‖ S_{ref}) is large when S_i deviates from reference

Behavioral signature: Agents converge on focal points or Schelling attractors because symbolic framing makes certain outcomes "obviously correct."

Empirical examples:

  • PD-Community Game (66% cooperation): "Community" frame activates prosocial symbolics
  • PD-Communication (72% cooperation): Discussion builds shared narrative
  • Stag Hunt-Hunter Narrative (73% cooperation): Story makes cooperation feel natural

Basin topology: Deep wells centered on symbolically-loaded strategy profiles. Difficult to escape once entered.

Mechanism analogy: Schelling focal points, but with field-theoretic formalization.

4.4 RET-4: Interference Zones

Definition: Regions of phase space where competing symbolic or temporal structures create destabilization.

Activation condition:

δφ_i ≥ 0.75 OR H_i ≤ 0.25 (high drift or low field harmony)

Mathematical signature:

λ_{φ} ‖δφ_i‖^2 + λ_H(1 - H_i) ≫ λ_S D_{KL} + λ_R |R_i - R̄|

Behavioral signature: Erratic, unpredictable behavior. Agents fail to coordinate even when cooperation would be beneficial. Symbolic conflicts prevent stable equilibrium.

Empirical example: PD-Wall Street Frame (33% cooperation vs 66% in Community Frame) - competitive framing creates interference, reducing cooperation despite identical payoffs.

Basin topology: Saddle points, chaotic regions, or flat regions with no clear attractor. High sensitivity to initial conditions.

Mechanism analogy: Destructive interference in wave mechanics.

4.5 RET-5: Precessive Shifts

Definition: Anticipatory strategy changes that precede explicit payoff justification, driven by early field sensing.

Activation condition:

dψ/dt > 0 AND one agent signals commitment

Mathematical signature:

(∂ ũ_i) / (∂ s_i)|_{t_0} < 0 BUT agent shifts anyway due to dψ/dt|_{t_0} > 0

Behavioral signature: Agents act before the current payoff gradient justifies it, anticipating future field shifts. Creates cascade effects.

Empirical example: In coordination games with sequential signaling, early movers who commit to risky strategy induce followers to coordinate on that strategy before payoff structure makes it Nash-optimal.

Basin topology: Trajectories that "roll uphill" temporarily before field reconfiguration makes the peak a valley.

Mechanism analogy: Precession of gyroscopes; anticipatory control in dynamical systems.

5.1 Design 1: 3-Agent Coordination Game

5.1.1 Game Structure

Three agents simultaneously choose between Legacy (L) or Innovative (I) technology:

Payoff structure:

  • All choose I: Each receives 10 (optimal)
  • All choose L: Each receives 7 (safe but suboptimal)
  • Mixed: Those choosing I receive 2, those choosing L receive 5

Nash analysis:

@dataclass
class DHVState:
    """Delta Harmonic Vector state representation"""
    S: float  # Symbolic compression [0,1]
    R: float  # Temporal rhythm [0,1]
    phi: float  # Phase angle [0, 2π]
    H: float  # Field harmony [0,1]
    
    def __post_init__(self):
        """Ensure values in valid ranges"""
        self.S = np.clip(self.S, 0, 1)
        self.R = np.clip(self.R, 0, 1)
        self.phi = self.phi % (2 * np.pi)
        self.H = np.clip(self.H, 0, 1)
    
    def delta_phi_to(self, other: 'DHVState') -> float:
        """Compute phase misalignment to another state"""
        phase_diff = abs(self.phi - other.phi)
        # Circular distance
        return min(phase_diff, 2*np.pi - phase_diff)
    
    def compute_dhv_magnitude(self, weights=(0.3, 0.3, 0.2, 0.2)) -> float:
        """Compute weighted geometric mean ΔHV"""
        w_S, w_R, w_F, w_H = weights
        delta_phi_normalized = 1 - (self.delta_phi_to(DHVState(0,0,0,0)) / np.pi)
        
        product = (self.S ** w_S * 
                   self.R ** w_R * 
                   delta_phi_normalized ** w_F * 
                   self.H ** w_H)
        
        return product ** (1 / sum(weights))


@dataclass
class RETParameters:
    """RET coherence cost parameters"""
    lambda_symbolic: float = 5.0
    lambda_phase: float = 3.0
    lambda_temporal: float = 2.0
    lambda_field: float = 3.0
    lambda_alignment: float = 4.0
    
    temperature: float = 0.6
    cost_model: str = 'linear'
    
    def compute_cost_component(self, value: float, lambda_weight: float) -> float:
        """Compute single coherence cost component"""
        misalignment = 1.0 - value
        
        if self.cost_model == 'linear':
            return lambda_weight * misalignment
        elif self.cost_model == 'quadratic':
            return lambda_weight * (misalignment ** 2)
        elif self.cost_model == 'cubic':
            return lambda_weight * (misalignment ** 3)
        else:
            raise ValueError(f"Unknown cost model: {self.cost_model}")


class RETAgent:
    """Agent with RET decision-making"""
    
    def __init__(self, name: str, dhv_state: DHVState, params: RETParameters):
        self.name = name
        self.dhv = dhv_state
        self.params = params
        
        # History tracking
        self.action_history = []
        self.utility_history = []
        self.cost_history = []
        
    def field_cooperation_score(self) -> float:
        """Compute ψ: how much field favors cooperation"""
        return (0.50 * self.dhv.S + 
                0.30 * (1 - self.dhv.delta_phi_to(DHVState(0,0,0,0)) / np.pi) +
                0.20 * self.dhv.H)
    
    def coherence_cost_base(self, system_R_bar: float = 0.5) -> float:
        """Compute structural coherence costs (action-independent)"""
        # Phase cost
        phase_misalignment = self.dhv.delta_phi_to(DHVState(0,0,0,0)) / np.pi
        C_phase = self.params.compute_cost_component(
            1 - phase_misalignment, self.params.lambda_phase
        )
        
        # Symbolic cost (assuming reference S=1.0)
        C_symbolic = self.params.compute_cost_component(
            self.dhv.S, self.params.lambda_symbolic
        )
        
        # Temporal cost
        temporal_alignment = 1.0 - abs(self.dhv.R - system_R_bar)
        C_temporal = self.params.compute_cost_component(
            temporal_alignment, self.params.lambda_temporal
        )
        
        # Field cost
        C_field = self.params.compute_cost_component(
            self.dhv.H, self.params.lambda_field
        )
        
        return C_phase + C_symbolic + C_temporal + C_field
    
    def action_alignment_cost(self, action: str) -> float:
        """Compute action-conditional coherence cost"""
        psi = self.field_cooperation_score()
        
        if action == 'cooperate':
            alignment = psi  # Cooperation aligned when ψ high
        else:  # defect
            alignment = 1 - psi  # Defection aligned when ψ low
        
        return self.params.compute_cost_component(
            alignment, self.params.lambda_alignment
        )
    
    def total_coherence_cost(self, action: str, system_R_bar: float = 0.5) -> float:
        """Total coherence cost for action"""
        return (self.coherence_cost_base(system_R_bar) + 
                self.action_alignment_cost(action))
    
    def choose_action(self, game_payoffs: dict, opponent_last_action: Optional[str] = None,
                     system_R_bar: float = 0.5) -> str:
        """Select action via softmax over coherence-adjusted utilities"""
        
        # Assume opponent will repeat last action (or cooperate if first round)
        if opponent_last_action is None:
            opponent_last_action = 'cooperate'
        
        # Compute coherence-adjusted utility for each action
        utilities = {}
        for action in ['cooperate', 'defect']:
            # Get payoff
            payoff = game_payoffs[(action, opponent_last_action)][0]  # This agent's payoff
            
            # Compute coherence cost
            cost = self.total_coherence_cost(action, system_R_bar)
            
            # Adjusted utility
            utilities[action] = payoff - cost
        
        # Softmax selection
        temp = self.params.temperature
        exp_utilities = {a: np.exp(u / temp) for a, u in utilities.items()}
        total = sum(exp_utilities.values())
        probs = {a: e / total for a, e in exp_utilities.items()}
        
        # Sample
        actions = list(probs.keys())
        probabilities = list(probs.values())
        return np.random.choice(actions, p=probabilities)

class RETGameSimulator:
    """Simulate RET-based game dynamics"""
    
    def __init__(self, game_payoffs: dict, agent1: RETAgent, agent2: RETAgent):
        self.game = game_payoffs
        self.agent1 = agent1
        self.agent2 = agent2
    
    def run_episode(self, rounds: int = 50, convergence_window: int = 8) -> dict:
        """Run game for specified rounds"""
        
        action1_history = []
        action2_history = []
        last1, last2 = None, None
        
        converged = False
        convergence_round = None
        
        for t in range(rounds):
            # System average rhythm
            system_R_bar = (self.agent1.dhv.R + self.agent2.dhv.R) / 2
            
            # Agents choose
            action1 = self.agent1.choose_action(self.game, last2, system_R_bar)
            action2 = self.agent2.choose_action(self.game, last1, system_R_bar)
            
            # Record
            action1_history.append(action1)
            action2_history.append(action2)
            
            # Update last actions
            last1, last2 = action1, action2
            
            # Check convergence
            if t >= convergence_window and not converged:
                recent = list(zip(
                    action1_history[-convergence_window:],
                    action2_history[-convergence_window:]
                ))
                if len(set(recent)) == 1:  # All same
                    converged = True
                    convergence_round = t
        
        # Compute final cooperation rate
        coop_rounds = sum(1 for a1, a2 in zip(action1_history, action2_history)
                         if a1 == 'cooperate' and a2 == 'cooperate')
        cooperation_rate = coop_rounds / rounds
        
        return {
            'cooperation_rate': cooperation_rate,
            'converged': converged,
            'convergence_round': convergence_round,
            'action_history': (action1_history, action2_history)
        }

Cross-Validation Procedure


def cross_validate(benchmarks: list, param_grid: list, train_ratio: float = 0.67) -> dict:
    """
    Perform cross-validation with train/test split
    """
    # Split benchmarks
    n_train = int(len(benchmarks) * train_ratio)
    train_benchmarks = benchmarks[:n_train]
    test_benchmarks = benchmarks[n_train:]
    
    # Search on training set
    best_params, train_results = parameter_grid_search(train_benchmarks, param_grid)
    
    # Validate on test set
    test_errors = []
    for benchmark in test_benchmarks:
        pred_rate = run_benchmark_validation(benchmark, best_params, trials=40)
        obs_rate = benchmark['observed_rate']
        
        if obs_rate is not None:
            test_errors.append(abs(pred_rate - obs_rate))
    
    return {
        'best_params': best_params,
        'train_error': np.mean([r['mean_error'] for r in train_results]),
        'test_error': np.mean(test_errors) if test_errors else None,
        'train_results': train_results
    }

Significance Testing


def compute_significance(ret_errors: list, nash_errors: list) -> dict:
    """
    Compute statistical significance of RET improvement
    """
    from scipy import stats
    
    # Paired t-test
    t_stat, p_value = stats.ttest_rel(nash_errors, ret_errors)
    
    # Effect size (Cohen's d)
    mean_diff = np.mean(np.array(nash_errors) - np.array(ret_errors))
    pooled_std = np.sqrt((np.var(nash_errors) + np.var(ret_errors)) / 2)
    cohens_d = mean_diff / pooled_std
    
    return {
        't_statistic': t_stat,
        'p_value': p_value,
        'cohens_d': cohens_d,
        'significant': p_value < 0.05
    }
